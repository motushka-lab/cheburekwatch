# CheburekWatch V7

## Исправления

- Вход по ссылке `/room/CODE`: если авторизованный пользователь ещё не участник, комната автоматически добавляет его.
- Вход по коду из раздела «Мои комнаты» сохранён.
- Серверное состояние playback теперь отдаёт `seq`, чтобы старые SSE-события не могли перезаписать новые.
- Исправлена синхронизация YouTube play/pause/seek.
- Перемотка YouTube теперь сохраняет реальное состояние play/pause, а не всегда отправляет `playing=true`.
- Увеличено окно подавления обратных событий после удалённого состояния, чтобы remote play/pause не превращался в повторную локальную команду.
- Добавлена синхронизация VK Video через официальный JS API `VK.VideoPlayer`, включая play, pause, seek и позицию.
- VK Video embed загружается с `js_api=1`.
- Прямые видео продолжают синхронизироваться через HTML5 Video API.
- Состояние синхронизации корректируется по времени `updatedAt`, поэтому новые подключившиеся участники получают актуальную позицию.

## Важно

Автозапуск со звуком может блокироваться политикой autoplay браузера. В таком случае пользователь должен один раз взаимодействовать с плеером; после этого серверная синхронизация продолжает работать.
