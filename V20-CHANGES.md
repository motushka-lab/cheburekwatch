# CheburekWatch V20 — Photo Archive Cut

## Что изменено
- Добавлен весь пользовательский фотоархив в `public/media/`.
- Главный экран получил реальные фото в hero-постерах.
- Добавлена стилизованная кинолента «Кадры, которые заслужили отдельный экран» со всеми 12 фото.
- Интро усилено: киноплёнка из фото, лучи, занавес, sweep-анимации и мягкий выход.
- Профиль получил Memory Reel.
- Пустой видеоплеер теперь выглядит как полноценный cinematic state, а не голый текст.
- Устранён лишний двойной обработчик кликов комнат; удаление и открытие комнат обрабатываются одним делегированным listener.
- Убран inline style у поля кода комнаты.
- Усилены CSS-ограничения для hero/grid/flex: `min-width:0`, `max-width:100%`, `overflow-x:hidden`, отдельные mobile bounds — чтобы заголовок не выезжал за колонку.
- Удалены старые дублирующие V12 frontend-файлы из `public/`.
- Cache-busting фронтенда обновлён до V20.

## Проверки
- `node --check public/app.js`
- `node --check server.js`
- ZIP integrity
