CHEBUREKWATCH — САМЫЙ ПРОСТОЙ ЗАПУСК

Цель:
Твой ПК запускает CheburekWatch локально, а Pinggy выдаёт публичную HTTPS-ссылку.
Для одного друга этого достаточно. Docker НЕ нужен.

1. Установи Node.js 18 или новее:
   https://nodejs.org/

2. Распакуй проект в любую папку, например:
   C:\CheburekWatch

3. Дважды нажми:
   START.bat

4. При первом запуске скрипт сам выполнит npm install.

5. В открывшемся окне появится HTTPS-адрес Pinggy, например:
   https://xxxxx.a.pinggy.link

6. Отправь ЭТУ HTTPS-ссылку другу.

7. Не закрывай окно START.bat, пока идёт просмотр.

8. После просмотра нажми STOP.bat.

ВАЖНО:
- Бесплатный Pinggy сейчас ограничивает один туннель 60 минутами. После завершения туннеля URL меняется.
- Сам CheburekWatch работает на твоём ПК: локальный адрес http://127.0.0.1:3000.
- Порт 3000 не открывается в интернет напрямую.
- Для Windows 10/11 нужен OpenSSH Client. Обычно он уже установлен.
- Если START.bat пишет, что ssh не найден:
  Параметры Windows -> Приложения -> Дополнительные компоненты -> Добавить компонент -> OpenSSH Client.

Если START.bat не запускается:
1) открой PowerShell в папке проекта;
2) выполни: npm install
3) затем: npm start
4) проверь http://127.0.0.1:3000

После этого снова запусти START.bat.
