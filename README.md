# CheburekWatch

Сайт для совместного просмотра: комнаты и приглашения, синхронизация видео, чат и реакции, профили и Telegram-библиотека.

## Запуск

Нужен Node.js 18+ и npm. В корне проекта выполни:

```bash
npm ci
npm start
```

Сайт: http://localhost:3000. Проверка сервера: http://localhost:3000/health.

Для разработки с перезапуском сервера при изменениях: `npm run dev`.

## Структура

| Путь | Что находится внутри |
| --- | --- |
| `server.js` | Express API, комнаты, синхронизация и Telegram-бот |
| `public/` | Интерфейс, стили и готовые медиафайлы сайта |
| `docs/` | Инструкции по развёртыванию и запуску в Windows |
| `scripts/windows/` | Windows-скрипты запуска, проверки и остановки |
| `render.yaml` | Конфигурация сервиса Render |
| `.env.example` | Список переменных окружения без секретов |
| `.github/workflows/` | Проверки кода в GitHub Actions |

Картинки и ролики в `public/site-assets/` обслуживаются по адресам `/site-assets/...`. Видео для главного экрана на ПК находится в `public/media/`. Архивы и распаковка при запуске не нужны.

## Инструкции

- [Развёртывание на Render](docs/deployment.md).
- [Запуск в Windows с временной публичной ссылкой](docs/windows.md).

База хранится в `data/db.json`, а при заданном `DATA_DIR` — в этой директории. На Render используется `/var/data/db.json` на постоянном диске. Рабочая база, секреты и установленные зависимости исключены из Git.

Приложение запускает backend на Node.js и рассчитано на один сервер с постоянным диском. GitHub Pages для него не подходит.

Старые описания версий и удалённые файлы доступны в истории Git
