# Запуск в Windows

[Вернуться к README](../README.md)

Обычный локальный запуск: открой терминал в корне проекта, выполни `npm ci`, затем `npm start`. Сайт откроется по адресу http://localhost:3000.

## Временная публичная ссылка

Скрипты находятся в [scripts/windows](../scripts/windows/). Для их работы нужны Node.js и OpenSSH Client с командой `ssh`.

1. Открой `scripts/windows/START.bat` двойным щелчком.
2. Скрипт проверит зависимости, запустит сервер на `127.0.0.1:3000` и откроет SSH-туннель через `nokey@localhost.run`.
3. Скопируй HTTPS-адрес, который покажет туннель, и отправь его другу.
4. Во время просмотра оставляй компьютер включённым, окно туннеля открытым и сервер запущенным.
5. После просмотра закрой туннель и запусти `scripts/windows/STOP.bat` для остановки окна сервера.

Для диагностики используй `scripts/windows/CHECK.bat` и адрес http://127.0.0.1:3000/health. Туннель предназначен для временного запуска; постоянный сайт работает на Render.
