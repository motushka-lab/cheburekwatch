# CheburekWatch — One Friend Mode

Для сценария **ты + один друг** Docker и настройка роутера не нужны.
Твой Windows-ПК запускает Node.js-сервер локально, а `START.bat` создаёт публичный HTTPS-туннель через localhost.run.

## Один раз

1. Установи Node.js 20+ с официального сайта: https://nodejs.org/
2. Убедись, что в Windows есть **OpenSSH Client**:
   `Параметры → Приложения → Дополнительные компоненты → Просмотреть компоненты → OpenSSH Client`.

## Каждый раз

Просто дважды нажми:

**`START.bat`**

Скрипт:

1. проверит Node.js;
2. проверит OpenSSH;
3. при первом запуске установит npm-зависимости;
4. запустит CheburekWatch на `127.0.0.1:3000`;
5. проверит, что сервер отвечает;
6. откроет бесплатный HTTPS-туннель через `nokey@localhost.run`;
7. покажет публичный HTTPS-адрес.

Скопируй появившийся `https://...` адрес и отправь его одному другу.

### Пароль вводить НЕ нужно

Мы используем документированный бесплатный режим localhost.run:

`ssh -R 80:localhost:8080 nokey@localhost.run`

В скрипте включён `BatchMode=yes`, поэтому он не должен останавливаться на запросе пароля.

### Не закрывай окно

Пока вы смотрите:

- не закрывай окно `START.bat`/туннеля;
- не закрывай процесс `CheburekWatch Server`;
- твой ПК должен быть включён;
- интернет должен работать.

## Остановка

Дважды нажми **`STOP.bat`**.

## Если что-то не работает

Дважды нажми **`CHECK.bat`** и пришли сюда весь вывод.

Также можно проверить локально:

`http://127.0.0.1:3000`

## Важно

Бесплатный публичный адрес localhost.run может меняться после переподключения туннеля. Это нормально для временного совместного просмотра.
